Kiln Ticket

Studio support

Kiln Ticket tracks pottery from drop-off to pickup on iPhone.

Using your firing desk

  1. Set your usual firing fee in Studio. Each new ticket starts with that rate.
  2. Open Tickets and select New firing order. Add the maker and a name for each piece.
  3. Build a load from waiting pieces. When you unload the kiln, record the pickup shelf.
  4. Open the ticket to share a pickup message. Record payment and collection separately.

Purchases and backups

The first three orders are free. A single purchase unlocks unlimited orders. To restore a purchase, use the same Apple Account and select Studio → Studio purchase → Restore purchases.

Use Studio → Export studio backup to save tickets and photos. Restoring a backup replaces your current studio records.

Contact support

Send a support request with your iOS version and the steps that caused the problem. Support requests on GitHub are public. Omit customer names, photographs and backup files.
